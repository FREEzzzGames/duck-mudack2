# 🦆 DUCK MUDACK — SPACE OUTPOST

Аркадная мини-игра в ретро-космическом сеттинге, написанная на чистом JavaScript (HTML5 Canvas). Цель игры — вовремя сканировать и уничтожать кибер-уток до истечения таймера.

🔗 **[Играть онлайн (GitHub Pages)](https://твой-логин.github.io/duck-mudack/)**

---

## 🎮 Особенности игры
* **Три уровня сложности:** EASY (6 уток), NORMAL (12 уток) и EXPERT (бесконечный режим).
* **Динамический геймплей:** Система комбо, анимированный лазерный прицел и процедурный фон (звезды, туманности, планеты).
* **Адаптивность:** Полная поддержка мобильных устройств и ПК (управление через Touch / Mouse).
* **Сохранение рекордов:** Используется `localStorage` для отслеживания лучшего счёта.

## 🛠️ Технологии
* HTML5 / CSS3 (Grid, Flexbox, Custom Properties, Animations)
* JavaScript (ES6+, Canvas API, RequestAnimationFrame)
* Без внешних библиотек и зависимостей (Vanilla JS)
